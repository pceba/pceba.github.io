# pceba.github.io

Personal site of Pablo Ceballos Arenas — live at **https://pceba.github.io**.

Plain HTML, CSS and a few lines of JavaScript. No build step, no dependencies.

```
index.html      page content
styles.css      design tokens, layout, light/dark themes
main.js         theme toggle, active nav, fade-in
assets/img/     optimised photos
```

## Run locally

```bash
python -m http.server 8080
```

Then open http://localhost:8080.

## Publish

Push to `main`. GitHub Pages redeploys automatically in about a minute.
