# pceba.github.io

Personal site of Pablo Ceballos Arenas — live at **https://pceba.github.io**.

Plain HTML, CSS and a few lines of JavaScript. No build step, no dependencies.

```
index.html      page content
styles.css      palette, typography, layout
main.js         neuron portrait, tile tilt, clocks, lightbox
assets/img/     optimised photos (portrait, club, campuses)
assets/logos/   company and university logos
```

## Run locally

```bash
python -m http.server 8080
```

Then open http://localhost:8080.

## Publish

Push to `main`. GitHub Pages redeploys automatically in about a minute.
